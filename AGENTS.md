# Project Description for Gemini CLI

This project is a Python development environment named "playground-bluetooth".

## Key Characteristics

* **Language:** Python 3.14
* **Dependency Management:** `uv` is used for managing project dependencies.
* **Purpose:** Currently a placeholder, likely intended for exploring Bluetooth
  functionalities or as a base for a command-line interface (CLI) tool.

## Development Environment Setup

To set up the development environment, use `uv` to create a virtual environment
and install dependencies:

```bash
uv venv
source .venv/bin/activate
uv pip install -e .
```

## Running the Application

The main application can be run using:

```bash
python main.py
```
